## Problems Solved

### 1. Diagonal Difference
Calculates the absolute difference between the sums of the two
diagonals of a square matrix.

### 2. Dynamic Array
Uses dynamic arrays and bitwise XOR to process queries.

### 3. Time Conversion
Converts 12-hour AM/PM format into 24-hour military time format.

### 4. Compare the Triplets
Compares the corresponding scores of Alice and Bob and calculates
their respective scores.

### 5. Sparse Arrays
Counts how many times each query string occurs in the given list
of strings.
